#  How Simple Can It Get? From Interpretable Equations to Readable Rules
#  for Financial Decision Making
#
#  This file declares the Python dependency set required to execute the
#  production-grade implementation of the reproduction protocol for "How
#  Simple Can It Get? From Interpretable Equations to Readable Rules for
#  Financial Decision Making" by Adia Lumadjeng, Ilker Birbil, and Erman
#  Acar (2026). It delivers a decision-grade explanation and governance
#  system that converts an already interpretable but operationally
#  unreadable learned equation into the simplest human-actionable
#  representation appropriate to each stakeholder - customer, loan officer,
#  fraud investigator, model validator, or regulator - with the predictive,
#  fidelity, and calibration costs of that conversion explicitly quantified
#  and, where possible, predicted before deployment.
#
#  Core Methodological Components:
#  - ECSEL single-term monomial classifier z(x) = alpha * prod_j x_j^beta_j
#  - Log-space transformation: log|z(x)| = log|alpha| + sum_j beta_j log x_j
#  - Worst-case pruning perturbation bound: |s_full - s_pruned| <= L * sum|beta_j|
#  - Directional-rule fidelity prediction via Pearson rho and Greiner's relation
#  - Scorecard and tally construction with validation-selected integer thresholds
#  - Iterative hard thresholding (IHT) as an independent sparsity route
#  - Isotonic calibration and expected calibration error (ECE) computation
#  - Tie-corrected Kendall's tau_b rank-fidelity measurement
#
#  Technical Implementation Features:
#  - PyTorch automatic differentiation for exact monomial gradients
#  - Optuna TPE Bayesian hyperparameter search with median pruning
#  - Stratified 60/20/20 splits over five reproducible random seeds
#  - Leakage-safe, training-only scaling, imputation, and count construction
#  - Versioned artifact persistence with SHA-256 integrity checksums
#  - Mathematical unit-test audit suite (log-space identity, pruning bound,
#    rho formula, ECE binning, scorecard points, Kendall tau_b)
#  - Human readability and preference assessment with ethics protocol
#
#  Dependency policy:
#  - Every third-party import used by the pipeline maps to exactly one
#    package below; no import in the module's import block is left out.
#  - Version floors are set to the earliest releases with full Python 3.11
#    support. Exact, machine-pinned versions are captured at runtime by the
#    environment-documentation stage (write_environment_documentation) and
#    recorded in environment_documentation.json for audit.
#  - A CPU build of PyTorch is sufficient: the ECSEL monomial is trained
#    with full-batch gradient descent on a small parameter vector.
#
#  Paper Reference:
#  Lumadjeng, A., Birbil, I., & Acar, E. (2026). How Simple Can It Get? From
#  Interpretable Equations to Readable Rules for Financial Decision Making.
